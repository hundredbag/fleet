## Variant: Discovery Workbench

> **Disposition: retained design reference with partial adoption.** The
> discovery grouping and card-workbench ideas were adopted, while the
> warm/orange visual identity was explicitly rejected in favor of Fleet's shared
> teal/neutral system. This sketch is not production code, is not imported at
> runtime, and is excluded from the npm package.

### Design stance

새 기능 탐색과 안전한 설치 전 검토를 중심으로 잡은 editorial marketplace형 화면이다.

### Key choices

- Layout: 추천 카드 피드 + 우측 업데이트/상태 rail
- Typography: Georgia headline + system body
- Color: warm neutral + orange accent
- Interaction: 검색, capability 필터, install bottom sheet, toast

### Trade-offs

- Strong at: 새 기능을 둘러보고 설치하는 경험, 친근한 제품성
- Weak at: 기존 설치 상태와 drift 운영에는 덜 효율적

### Best for

- discovery feed가 주요 진입점인 사용자
